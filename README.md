### 4.2 데이터베이스 연결 방식 및 Firebase 클라우드 연동 가이드

* **초기 상태 (브라우저 로컬 스토리지 모드)**:
  * 본인의 Firebase 프로젝트 키(`apiKey`, `projectId` 등)가 등록되기 전에는 시스템이 에러로 중단되지 않도록 웹 브라우저의 내부 저장소인 **`localStorage` (웹 브라우저 로컬 데이터베이스: `cafecore_users_v1`)**를 데이터베이스로 사용하여 동작합니다.

* **실제 Firebase 클라우드 연동 완료 (Cloud Firestore & Auth)**:
  * **프로젝트 ID**: `iceu-songpa03`
  * **웹 앱**: `cafeapp` (`appId: 1:94943462326:web:b6b604f9fb224670243717`)
  * 이제 회원가입한 모든 회원은 구글 Firebase 콘솔의 **Authentication** 및 **Cloud Firestore (`users` 컬렉션)**에 실시간으로 영구 기록됩니다.

### 4.3 오늘 신규 가입 회원 관리 콘솔 (`store-manage.html`)

* **오늘 신규 가입 회원 목록 표시**:

  * 저장소 출처 뱃지(`Firestore` 녹색 vs `Local` 황색)를 함께 표시하여 어떤 데이터베이스에 저장되었는지 한눈에 직관적으로 구분 가능.
  * 표시 항목: `순번`, `이름 및 UID`, `이메일`, `연락처`, `가입 시각(HH:MM:SS)`, `인증 상태(✓ 자동 인증 완료)`.
  * 상단에 **오늘 가입 N명 뱃지** 및 누적 일반 회원 수 실시간 집계.
  * `[+ 신규 가입 시뮬레이션]` 버튼으로 실시간 회원 유입 테스트 가능.

## 5. 각 코드 파일별 상세 브리핑

### 5.1 HTML 화면 계층 (6대 독립 웹페이지)

#### ① `index.html` (메인 포털 허브)
* **역할**: 전체 서비스의 관문 역할을 하는 메인 홈페이지.
* **동작**: 각 화면 카드를 누르면 `target="_blank"`로 새 탭이 열립니다.
* **관리자 감지**: 관리자(`admin@gmail.com`) 로그인 시 상단에 '오늘 신규 회원 현황 알림 바'와 6번째 카드인 '매장 & 신규회원 관리' 카드가 즉시 나타납니다.

#### ② `store-manage.html` (👑 매장 관리 & 오늘 신규 가입 회원 콘솔)
* **역할**: 오직 관리자만 접근할 수 있는 매장 관리자 전용 페이지.
* **주요 구성**: 오늘 가입한 신규 회원 목록 테이블(자동 인증 완료), 가입 통계 KPI, 매장 운영 상태(정상 영업 중), 관리자 보안 가드 오버레이.

#### ③ `pwa-order.html` (스마트폰 PWA 모바일 주문)
* **역할**: 모바일 전용 비대면 주문 웹앱.
* **주요 구성**: PWA 설치 유도 배너, 2열 메뉴 그리드, 하단 고정 주문 바, 장바구니 드로어 모달, 실시간 '내 주문' 3단계 상태 트래킹 모달.
* **주문 전 수량 제어**:
  * 초기 상태 0잔(빈 장바구니)으로 시작.
  * 메뉴 카드에서 `[-] N [+]` 스텝퍼로 즉시 수량 조절 가능.
  * 장바구니 상세 모달에서 품목 개별 삭제(✕) 및 전체 비우기 지원.
* **실시간 내 주문 트래킹 고도화**:
  * 사용자가 실제로 `[주문하기]`를 완료한 본인의 실제 주문만 영구 저장(`cafecore_pwa_my_order_ids_v1`)하여 정확히 추적.
  * 주문 전에는 "아직 접수된 내 주문이 없습니다"라는 친절한 Empty State 표시 (타인/시스템 예시 주문 노출 원천 차단).
  * 복수 주문 발생 시 주문번호별 탭 스위처 지원.

#### ④ `kiosk.html` (매장 키오스크 주문)
* **역할**: 매장 터치 키오스크 전용 화면.
* **주요 구성**: 직원 호출 긴급 버튼, ICE/HOT 온도 선택 모달, 장바구니 수량 스텝퍼, 원터치 결제 및 주문번호/영수증 모달.

#### ⑤ `kitchen.html` (주방 디스플레이 KDS)
* **역할**: 바리스타용 실시간 조리 제어 화면.
* **주요 구성**: 접수된 주문 3열 카드, 초 단위 타이머, 메뉴별 조리 완료 체크박스, `[제조 시작]` ➔ `[픽업 준비 완료]` 단계별 원터치 처리.

#### ⑥ `pickup-board.html` (음료 주문 상황판 DID)
* **역할**: 매장 대형 모니터용 16:9 와이드 픽업 안내 화면.
* **주요 구성**: 실시간 디지털 시계, [제조 중] 타일 vs [픽업 가능] 대형 카드, 신규 완료 시 '방금 완료' 골드 하이라이트 & 딩동 차임벨 소리.

#### ⑦ `sales-dashboard.html` (판매 & 매출 대시보드)
* **역할**: 점주/관리자용 실시간 매출 통계 대시보드.
* **주요 구성**: 4대 KPI 요약(결제액, 순매출, 환불액, 총 주문/잔수), 음료별 순매출 수평 바, 시간대별 세로 막대 차트, 채널별 비중 바, CSV 내보내기.

### 5.2 JavaScript 로직 계층

#### ① `js/pwa.js` (스마트폰 PWA 주문 및 장바구니 & 내 주문 엔진)
* **장바구니 상태 관리**: `cart = []`로 0잔 시작, `changeMenuQty()`, `removeCartItem()`, `clearAllCart()`.
* **주문 접수 및 내 주문 바인딩**:
  * `submitOrder()`: 접수된 주문 번호를 `cafecore_pwa_my_order_ids_v1`에 저장하고, 주문 완료 팝업 오픈.
  * `renderMyOrderModalContent()`: 내가 실제로 접수한 주문만 필터링하여 레몬에이드 등 주문 메뉴와 실시간 조리 단계(접수 ➔ 제조 중 ➔ 픽업 가능)를 100% 일치시켜 렌더링.
  * 주문 미발생 시 시스템 샘플 폴백을 제거하고 직관적인 빈 상태 안내 렌더링.

#### ① `js/firebase-auth.js` (Firebase 인증 & 회원 데이터베이스 엔진)
* 관리자(`admin@gmail.com` / `password1234`) 및 기본 샘플 회원 시드.
* `signIn(email, password)`: 관리자/일반 회원 로그인 및 세션 저장.
* `signUp(email, password, name, phone)`: 회원가입 즉시 **자동 인증(`isVerified: true`)** 부여 및 자동 로그인.
* `getTodayNewUsers()`: 당일 가입한 일반 회원만 필터링하여 최신순 반환.
* `onAuthStateChanged(callback)`: 로그인/로그아웃 상태를 모든 탭에 브로드캐스팅.

#### ② `js/auth-ui.js` (공통 헤더 인증 UI 및 권한 제어)
* 어느 화면에서든 동작하는 로그인/회원가입 팝업 모달(`globalAuthModal`) 동적 주입.
* 관리자(`admin@gmail.com`) 로그인 시에만 글로벌 헤더의 `[매장 관리 ↗]` 탭 노출 (`nav-link-store-manage`).
* 원클릭 테스트 채우기 함수 `fillFastLogin()`.

#### ③ `js/store-manage.js` (매장 관리 & 신규 회원 렌더링)
* 비관리자 접근 시 `adminGuardOverlay` 활성화로 접근 차단.
* 오늘 신규 가입 회원 목록 테이블 렌더링 및 통계 수치 갱신.
* `simulateNewUserRegistration()`: 테스트용 신규 회원 가입 즉시 시뮬레이션.

#### ④ `js/store.js` (실시간 주문 & 매출 상태 스토어)
* `BroadcastChannel`과 `Storage Event`를 통한 다중 탭 간 실시간 데이터 동기화.
* 신규 주문 생성(`createOrder`), 조리 상태 변경(`updateOrderStatus`), 조리 체크(`toggleItemKitchenCheck`), 매출 집계(`getSalesSummary`).

## 7. 실행 및 시연 가이드

### 7.1 로컬 실행
```powershell
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`을 엽니다.

### 7.2 추천 시연 시나리오
1. **메인 화면에서 다른 탭 열기**:
   * 메인 페이지([index.html](http://localhost:8080))에서 원하는 카드를 클릭하면 **각각 다른 새 탭으로 페이지가 열립니다.**
2. **관리자 로그인 & 매장 관리 확인**:
   * 상단 우측 `[로그인]`을 클릭한 후, `[👑 관리자 계정 채우기]`를 누르고 로그인합니다.
   * 상단 네비게이션 및 메인 화면에 **`[매장 관리 ↗]`**가 나타납니다.
   * `[매장 관리 ↗]`를 클릭하여 다른 탭에서 열면, **오늘 신규 가입한 회원 목록(자동 인증 완료)**이 깔끔하게 표시됩니다.
3. **일반 회원가입 & 자동 인증 테스트**:
   * 모바일 주문 탭에서 `[로그아웃]` 후 `[회원가입]` 탭을 누릅니다.
   * 임의의 이름과 이메일로 가입을 완료하면, **즉시 자동 인증되어 로그인**됩니다.
   * 매장 관리 탭으로 돌아와 새로고침하면 방금 가입한 회원이 **'오늘 신규 가입 회원 목록'**에 실시간으로 등록된 것을 확인할 수 있습니다!
