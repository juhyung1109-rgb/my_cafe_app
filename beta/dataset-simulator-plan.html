Statistical Distribution

주문 소요 시간 확률 분포 모델

고객 유형과 채널 특성에 따라 로그정규분포(Log-Normal)를 적용해 극단치(고민이 긴 고객)를 자연스럽게 포함합니다.

time_to_order 확률 함수 (JavaScript) 
function generateTimeToOrder(isPreset, channel, random) {
  if (isPreset) {
    // 단골 1-Click: 평균 25초, 표준편차 8초
    return Math.round(15 + random() * 20) * 1000;
  }
  if (channel === 'KIOSK') {
    // 키오스크: 평균 62초 (뒷사람 대기 압박)
    return Math.round(35 + random() * 55) * 1000;
  }
  // PWA 일반 탐색: 평균 105초 (긴 체류)
  return Math.round(45 + Math.exp(4.3 + random() * 0.6)) * 1000;
}

07_cart_funnel.sql

장바구니 전환 퍼널 & 500건 이탈 사유 분석

5,000건 진입 세션 대비 장바구니 담기율, 결제 도달율, 500건 이탈 사유별 비중을 산출합니다.

SQL 스니펫 (500건 취소 분석) 
SELECT
  channel,
  COUNT(session_id) AS total_sessions, -- 총 5,000건
  COUNTIF(is_abandoned) AS abandoned_sessions, -- 500건
  ROUND(COUNTIF(is_abandoned) / COUNT(session_id) * 100, 2) AS abandonment_rate_pct, -- 10.0%
  COUNTIF(abandon_reason = 'TIMEOUT') AS drop_by_timeout,
  COUNTIF(abandon_reason = 'PRICE_HIGH') AS drop_by_price
FROM `sesac-dev-400904.cafe_analytics_demo.user_sessions`
GROUP BY channel;
08_time_to_order.sql

고객군·채널별 주문 소요 시간 (4,500건 분석)

회원 400명의 단골 프리셋 주문과 비회원 200명의 주문 소요 시간 차이를 백분위로 검증합니다.

SQL 스니펫 (4,500건 주문 완료 분석) 
SELECT
  channel,
  is_preset_order,
  ROUND(AVG(time_to_order_ms) / 1000, 1) AS avg_seconds,
  PERCENTILE_CONT(time_to_order_ms / 1000, 0.5) OVER(PARTITION BY channel) AS p50_seconds,
  PERCENTILE_CONT(time_to_order_ms / 1000, 0.9) OVER(PARTITION BY channel) AS p90_seconds
FROM `sesac-dev-400904.cafe_analytics_demo.orders`
WHERE status != 'CANCELLED';
09_search_insights.sql

검색어 Top 10 및 전환율 분석

고객이 검색창에 입력한 키워드 빈도와 실제 클릭된 메뉴 전환 성과를 추적합니다.

SQL 스니펫 
SELECT
  keyword,
  COUNT(*) AS search_count,
  COUNTIF(clicked_menu_id IS NOT NULL) AS click_count,
  ROUND(COUNTIF(clicked_menu_id IS NOT NULL) / COUNT(*) * 100, 1) AS click_through_rate_pct
FROM `sesac-dev-400904.cafe_analytics_demo.search_logs`
GROUP BY keyword
ORDER BY search_count DESC
LIMIT 10;
10_personalization.sql

취식 형태 & 텀블러 에코 지표

매장 회전율과 친환경 텀블러 컵 감면 혜택의 시계열 추이를 집계합니다.

SQL 스니펫 
SELECT
  packaging_type,
  cup_type,
  COUNT(*) AS order_count,
  SUM(total_amount) AS total_sales,
  ROUND(COUNT(*) / SUM(COUNT(*)) OVER() * 100, 2) AS share_pct
FROM `sesac-dev-400904.cafe_analytics_demo.orders`
GROUP BY packaging_type, cup_type
ORDER BY order_count DESC;
