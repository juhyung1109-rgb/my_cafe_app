01

프로젝트 배경: Beta 프로토타입의 한계와 Main 2.0 도약

단순한 과제 수준의 정적 분석에서 왜 실시간 스트리밍 & AI 개입 아키텍처로 진화해야 하는가?

BETA PHASE (PROTOTYPE)

⚠️ 기존 프로토타입의 한계점

1. 정적 배치(Batch)의 한계: 사전에 생성된 고정 5,000건 세션에 의존하여 피크타임(출근/점심) 병목 현상이나 날씨 영향을 반영하지 못함.
2. 사후 분류의 비즈니스 무용성: 이미 앱을 닫고 떠난 고객을 나중에 머신러닝으로 맞춰봤자 실제 카페 매출 개선에 기여할 수 없음.
3. 단일 매장 시나리오: 상권별(오피스 vs 대학가 vs 주거지) 차이가 없어 현실 카페 비즈니스 적용성이 제한적임.
4. 수동적 UX: 고객이 옵션을 일일이 클릭해야 하며, 주방 제조 소요 시간에 대한 정보가 없어 막연한 대기로 이탈 발생.

MAIN PHASE 2.0 (PRODUCTION-GRADE)

🚀 Main 고도화의 4대 핵심 가치

1. 실시간 이벤트 스트리밍: 3대 상권 클러스터, 기상 변수, 피크타임 병목을 모사한 20,000건 실시간 데이터 파이프라인.
2. 실시간 조기경보 & SHAP 개입 (Intervention): 장바구니 고민 중 이탈 위험도를 15ms 내에 예측하고, 원인에 맞춘 맞춤 혜택(쿠폰/빠른제조) 즉시 제공.
3. 하이브리드 개인화 추천 & KDS 대기시간 회귀: 고객 취향 옵션 자동완성 + 스마트 디저트 페어링 + 정밀 제조 대기시간 안내.
4. 실시간 A/B 테스트 검증: 대조군 대비 실험군의 전환율 및 객단가 상승을 정량적으로 증명하는 종합 관제 MLOps 시스템.

데이터 엔지니어링: 3대 상권 클러스터 & Star Schema 데이터 모델링

현실의 복합 맥락을 반영한 데이터 웨어하우스(Fact & Dimension) 설계

CLUSTER A: OFFICE

🏢 오피스 상권 (강남/여의도형)

• 피크타임: 08:00~09:30 출근 러시, 12:00~13:00 점심 러시
• 행동 패턴: 아메리카노 비율 68%, 빠른 테이크아웃(TO_GO 82%)
• 이탈 취약점: 대기열 병목(WAIT_TIME_LONG)에 극도로 민감
• 해결책: 원클릭 스마트오더 및 초고속 제조 대체 음료 추천

CLUSTER B: CAMPUS

🎓 대학가 상권 (신촌/혜화형)

• 피크타임: 13:00~16:30 오후 공강 및 스터디 타임
• 행동 패턴: 달콤한 논커피/스무디 및 디저트 비중 55%, 매장 이용(DINE_IN 72%)
• 이탈 취약점: 가격 부담(PRICE_HIGH) 민감도 높음
• 해결책: 베이커리 콤보 세트 할인 및 학생 멤버십 혜택 트리거

CLUSTER C: RESIDENTIAL

🏡 주거지 상권 (송파/마포형)

• 피크타임: 10:30~13:30 브런치 타임 및 주말 전 시간대
• 행동 패턴: 디카페인/오트밀크 건강 옵션 선호, 가족 단위 다잔 주문 (평균 2.8잔)
• 이탈 취약점: 복잡한 옵션 조작 피로도(TIMEOUT_60S)
• 해결책: 가족 즐겨찾기 옵션 묶음 및 디카페인 자동 프리셋

03

핵심 머신러닝 파이프라인 3종 (The ML Trio)

이탈 조기경보, 개인화 추천, 대기시간 회귀 모델의 상세 알고리즘 및 XAI 설계

ML MODEL 01 · CLASSIFICATION & XAI Latency: < 15ms

🛡️ 실시간 장바구니 이탈 조기경보 & SHAP 개입 엔진 (Early-Warning & Intervention)

고객이 장바구니 화면에서 고민하는 동안, 수집되는 행동 피처를 실시간으로 입력받아 이탈 확률 $P(\text{Abandon})$을 계산하고, SHAP(SHapley Additive exPlanations)을 통해 이탈의 주원인이 무엇인지 실시간 판별하여 즉각적인 개입 액션을 트리거합니다.

1. 실시간 입력 Features
• cart_dwell_time_sec (장바구니 체류초)
• option_toggle_count (옵션 변경 횟수)
• current_store_queue_length (대기열 잔수)
• price_to_avg_ratio (평균 대비 금액 비율)
• is_registered_member (회원 여부)
2. 머신러닝 알고리즘
• LightGBM Classifier (초고속 트리 분기)
• SHAP TreeExplainer (원인 기여도 분해)
• 평가지표: ROC-AUC > 0.88, F1-Score > 0.84
• Threshold: $P(\text{Abandon}) \ge 0.75$ 시 개입
3. SHAP 기반 동적 개입 액션
• PRICE_HIGH 기여도 1위:
→ "지금 결제 시 500원 즉시 할인 쿠폰" 팝업
• WAIT_TIME_LONG 기여도 1위:
→ "빠른 제조 음료(콜드브루)로 즉시 변경 옵션"
• TIMEOUT 기여도 1위: 원클릭 간편결제 안내
ML MODEL 02 · HYBRID RECOMMENDER ☕

🎯 하이브리드 개인화 추천 엔진 (Smart Recommender)

고객의 이전 주문 로그 및 현재 장바구니 구성을 분석하여, 탐색 시간을 대폭 줄이고 객단가를 높이는 3중 추천 구조를 제공합니다.

1. 선호 옵션 자동 프리셋 (Option Auto-preset): 고객이 아메리카노 클릭 시 과거 선호 옵션(ICE, 샷+1, 얼음많이)이 1순위로 자동 선택되어 주문 시간 72초 → 48초로 단축.
2. 스마트 장바구니 페어링 (Basket Cross-selling): FP-Growth 연관 규칙 기반, 아메리카노 담을 시 "플레인 베이글 세트 할인(+2,500원)" 추천으로 AOV +13.6% 증대.
3. 상황 인지형(Context-Aware) 메뉴 추천: 비 오는 아침 $\rightarrow$ 따뜻한 카페라떼 & 수프 / 폭염 오후 $\rightarrow$ 대용량 아이스 콜드브루 자동 제안.
ML MODEL 03 · REGRESSION ⏱️

⌛ KDS 주방 제조 대기시간 정밀 회귀 모델 (Wait-Time Regressor)

현재 주방 KDS 화면에 대기 중인 잔수와 메뉴별 제조 표준시간 및 바리스타 인력을 결합하여 고객에게 투명한 실시간 대기 시간을 안내합니다.

1. 입력 Feature: 대기 중인 총 음료 잔수, 복합 음료(스팀밀크/블렌더 난이도 가중치) 합산 점수, 근무 바리스타 인원수, 시간대 피크 플래그.
2. 알고리즘: Random Forest / Gradient Boosting Regressor (하이퍼파라미터 튜닝 최적화).
3. 정밀도 목표: Mean Absolute Error (MAE) < 45초 이내 달성.
4. 비즈니스 임팩트: 주문 전 "현재 예상 대기시간: 약 7분"을 사전 안내함으로써 막연한 대기 지연으로 인한 장바구니 포기를 30% 이상 사전 방지.

실시간 A/B 테스트 검증 프레임워크 (A/B Testing Framework)

AI 개입 시스템이 실제 매출과 전환율에 미치는 인과적 효과를 정량 검증

CONTROL GROUP (대조군: 50%)

기존 Beta 방식 (AI 개입 없음)

• 고객이 장바구니에서 머뭇거려도 시스템 개입 없음
• 고객이 옵션을 수동으로 일일이 선택
• 대기 시간에 대한 안내 부재
• 기존 전환율: 90.0% (포기율 10.0%)
• 평균 객단가: 4,750원

TREATMENT GROUP (실험군: 50%)

Main 2.0 AI 개입 시스템 적용

• 이탈 위험 감지 시 SHAP 맞춤형 혜택 팝업 실시간 발송
• 선호 옵션 프리셋 1초 자동완성 및 베이커리 페어링 추천
• KDS 정밀 대기시간("약 7분 후 수령") 투명한 안내
• 개선 전환율: 94.5% (포기율 5.5%로 -4.5%p 감소)
• 개선 객단가: 5,400원 (+13.6% 상승)

from fastapi import FastAPI, HTTPException from pydantic import BaseModel import lightgbm as lgb import shap import numpy as np app = FastAPI(title="CAFE CORE 2.0 AI Intervention Engine") # 1. 요청 페이로드 스키마 (실시간 세션 마이크로 피처) class SessionState(BaseModel): session_id: str user_id: str cart_dwell_time_sec: float option_toggle_count: int current_store_queue_length: int cart_amount: int user_past_aov: float is_registered_member: int @app.post("/api/v1/predict-abandon") def predict_and_intervene(state: SessionState): # 피처 벡터 변환 features = np.array([[ state.cart_dwell_time_sec, state.option_toggle_count, state.current_store_queue_length, state.cart_amount / max(1, state.user_past_aov), state.is_registered_member ]]) # LightGBM 초저지연 추론 prob = float(model.predict_proba(features)[0, 1]) # 이탈 위험 임계치(0.75) 초과 시 SHAP 분석 및 개입 정책 수립 if prob >= 0.75: shap_values = explainer.shap_values(features)[0] top_reason_idx = np.argmax(shap_values) reason_map = {0: "TIMEOUT", 1: "OPTION_FATIGUE", 2: "WAIT_TIME_LONG", 3: "PRICE_HIGH"} primary_reason = reason_map.get(top_reason_idx, "PRICE_HIGH") return { "session_id": state.session_id, "abandon_prob": round(prob, 4), "should_intervene": True, "primary_reason": primary_reason, "intervention_action": "DISCOUNT_COUPON_500" if primary_reason == "PRICE_HIGH" else "FAST_MENU_OFFER" } return {"session_id": state.session_id, "abandon_prob": round(prob, 4), "should_intervene": False}
