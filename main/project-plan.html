🧠 핵심 머신러닝 파이프라인 3종 (ML Trio)

중간 프로젝트 포트폴리오의 기술적 깊이를 증명할 3대 AI/ML 모델 명세서입니다.

CLASSIFICATION + XAI 🛡️

1. 실시간 장바구니 이탈 조기경보 모델

LightGBM Classifier + SHAP TreeExplainer
• 입력 Feature: 장바구니 체류시간(초), 옵션 토글 변경 횟수, 현재 매장 대기열 길이, 주문액 대비 과거 객단가 비율
• 출력: 실시간 이탈 위험 확률 $P(\text{Abandon}) \in [0, 1]$
• 비즈니스 액션: 위험도 > 0.75 시 SHAP 기여도 1위 요인(가격 vs 대기)에 맞춘 맞춤형 개입(Intervention) 팝업 발송
HYBRID RECOMMENDER ☕

2. 하이브리드 개인화 추천 엔진

Rule-based Preset + FP-Growth Basket Pairing
• 기능 A: 유저별 선호 원두/우유/온도 옵션 원클릭 자동 프리셋 (주문 리드타임 33% 단축)
• 기능 B: 장바구니 담긴 메뉴 기반 페어링 디저트 추천 (아메리카노 담을 시 베이글 세트 할인 추천)
• 기능 C: 기온/시간대 맥락 추천 (비 오는 아침: 핫라떼, 폭염 오후: 대용량 콜드브루)
REGRESSION FORECASTING ⏱️

3. KDS 주방 제조 대기시간 정밀 예측 모델

Random Forest / Gradient Boosting Regressor
• 입력 Feature: 주방 큐 잔여 잔수, 블렌더/스팀 메뉴 난이도 가중치 합, 근무 바리스타 인원수, 피크타임 플래그
• 목표 지표: MAE < 45초 이내 실시간 정확도 달성
• 비즈니스 임팩트: "현재 예상 대기: 약 7분" 투명한 안내로 대기 지연 이탈(WAIT_TIME_LONG) 30% 방지
